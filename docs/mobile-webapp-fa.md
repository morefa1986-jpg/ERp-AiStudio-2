# نصب وب‌اپ موبایل Fathi Aqua SuperERP

این نسخه برای آیفون، آیپد، اندروید و تبلت از مسیر مرورگر داخلی شبکه مزرعه اجرا می‌شود.

## آیفون و آیپد

1. آدرس ERP را در Safari باز کنید.
2. دکمه Share را بزنید.
3. گزینه Add to Home Screen را انتخاب کنید.
4. نام `Fathi ERP` را تأیید کنید.

## اندروید و تبلت

1. آدرس ERP را در Chrome باز کنید.
2. منوی سه‌نقطه را باز کنید.
3. Install app یا Add to Home screen را انتخاب کنید.

## نکته‌های اجرایی

- برای دسترسی موبایل در محوطه مزرعه، سیستم ویندوز میزبان باید روی همان شبکه LAN باشد.
- اولین ورود باید با کاربر مجاز انجام شود.
- عملیات حساس مانند تنظیمات ادمین، کاربران و بکاپ فقط برای نقش‌های مجاز فعال است.
