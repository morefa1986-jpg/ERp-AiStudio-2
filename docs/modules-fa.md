# فهرست بخش‌های ERP/CRM/اتوماسیون

| بخش | کاربرد |
| --- | --- |
| داشبورد مدیریتی | نمای کلی وضعیت مزرعه، هشدارها، KPIها و رخدادهای مهم |
| سالن‌ها و استخرها | ساختار سالن، استخر، ظرفیت، موجودی ماهی و وضعیت عملیاتی |
| تغذیه | ثبت خوراک، کنترل قطع غذا، محاسبه FCR و جلوگیری از پیشنهاد خوراک ناسالم |
| کیفیت آب | ثبت/پایش اکسیژن، دما، pH، آمونیاک، نیتریت و وضعیت سنسور |
| تلفات | ثبت تلفات روزانه، وزن تقریبی، علت، چیپ و گزارش مدیریتی |
| درمان‌ها | ثبت دارو، دوره درمان، withdrawal و کنترل قبل از فرآوری |
| انتقالات | انتقال اتمیک بین استخر، سردخانه، فرآوری و مقصدهای مجاز |
| تکثیر | مولد، لقاح، انکوباتور، لارو و رهگیری زنجیره تکثیر |
| نرسری | مدیریت تانک‌های نوزادگاهی و بچه‌ماهی |
| کارخانه خوراک | فرمول، مواد اولیه، تولید بچ، QC و انبار خوراک |
| انبار | موجودی، ورود/خروج، بچ، تاریخ انقضا و نقطه سفارش |
| آزمایشگاه | نمونه‌گیری، نتایج آزمایش، وضعیت QC و مستندات |
| فرآوری | ثبت بچ فرآوری، کنترل جرم، خروجی خاویار/فیله و اتصال به سردخانه |
| سردخانه | پالت/لات، موجودی قابل فروش، خروج کنترل‌شده و ردیابی محصول |
| فروش و CRM | مشتریان، پیش‌فاکتور، مرحله فروش، وصول مطالبات و تحویل |
| حسابداری | حساب‌ها، سند دوبل، تبدیل ارز، حقوق و ارتباط با فروش/انبار |
| منابع انسانی | پرسنل، حضور و غیاب، شیفت، حقوق و کسورات |
| دبیرخانه و اسناد | اندیکاتور، نامه وارده/صادره/داخلی، فایل اصل/PDF، سربرگ، امضا و مهر |
| نگهبانی و برگه خروج | ثبت ورود/خروج خودرو و کالا، راننده، صاحب کالا، بارنامه، حواله، مجوز حمل و چاپ برگه خروج |
| رسانه و شبکه‌های اجتماعی | کتابخانه عکس/ویدئو، آماده‌سازی کپشن، صف تأیید و انتشار کمکی |
| گزارش‌ها | خروجی CSV/XLSX/PDF برای بخش‌های عملیاتی، مالی، دبیرخانه و نگهبانی |
| امنیت و کاربران | نقش‌ها، دسترسی‌ها، audit، scope سالن/استخر و کنترل کاربران |
| بکاپ و بازیابی | backup رمزگذاری‌شده، restore، checksum و آمادگی بحران |
| چندسکویی | نسخه Windows، وب‌اپ موبایل، راهنمای نصب iOS/Android و LAN |
